Now without further ado.

A small browser userscript that makes **ChatGPT Project Sources behave like actual bookmarks**.

When a saved Project Source is clicked, ChatGPT already opens the correct conversation and includes the original message identifier in the URL. At the time this proof of concept was created, ChatGPT could still leave the user at the bottom of a long conversation instead of navigating to that original message.

Project Pin Jump fills in that last piece locally in the browser.

## What it does

1. Reads the `messageId` already present in the current ChatGPT URL.
2. Looks for the matching rendered element with `data-message-id`.
3. If that message is not currently mounted, moves upward through the conversation so virtualized/older messages can render.
4. Stops when the exact original message appears.
5. Scrolls directly to it and briefly highlights it.

No title matching is used. This matters because Project Source titles may be autogenerated and can differ completely from the text of the original response.

## What it does NOT do

- No OpenAI API calls.
- No undocumented backend requests.
- No conversation export.
- No scraping or saving of chat content.
- No account/session token access.
- No credential access.
- No bypass of authentication, paywalls, usage limits, or safety systems.
- No external network requests.
- No analytics or telemetry.
- No data leaves the browser.

The script only reads DOM state and URL information already present in the currently open ChatGPT page, then controls the page's existing conversation scrollbar.

## Installation

### Tampermonkey

1. Install Tampermonkey for your browser.
2. Create a new userscript.
3. Replace the default template with `chatgpt-project-pin-jump.user.js`.
4. Save it.
5. Make sure the script is enabled.

## Usage

Open a ChatGPT Project, open its Sources/Project Sources, and click a saved response.

If the source URL contains a `messageId`, the script searches the conversation for the exact original message and navigates to it.

On very long conversations, you may briefly see the page moving upward while the script searches through virtualized content.

## Why the script searches instead of jumping instantly

Long ChatGPT conversations may not keep every old message mounted in the browser DOM at once.

The Project Source URL can already identify the exact message, but the corresponding `[data-message-id]` element may not exist until the relevant part of the conversation has been brought into the rendered window.

The script therefore sweeps upward through the real chat scroll container and checks for the exact ID after each movement.

## Known limitations

This is a DOM-based browser enhancement, so changes to ChatGPT's frontend structure may require updates.

It currently targets:

- `https://chatgpt.com/*`
- Project Source links that expose a `messageId`
- Conversation turns rendered with `data-message-id`

The script intentionally avoids private APIs or internal application state.

## Privacy & security

Project Pin Jump has no network permissions and uses `@grant none`.

It does not transmit, persist, or process conversation text outside the page. Its only persistent state is the userscript itself.

For auditing, the complete behavior is contained in one small JavaScript file.
